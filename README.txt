STUDIO5 CONTENT CALENDAR - PRODUCTION PACKAGE

FILES
- index.html
- styles.css
- script.js
- firebase-config.js
- database.rules.json

WORKSPACE ACCESS
The login can remember access for 30 days. Use Lock Workspace to remove access from a device.

FIREBASE SETUP
1. Enable Authentication > Anonymous.
2. Open Realtime Database > Rules.
3. Paste the contents of database.rules.json and publish.
4. Upload all website files to your GitHub Pages repository.

IMPORTANT
The access-code screen is a front-end gate. Firebase anonymous authentication protects the database from unauthenticated requests, but the shared code is not server-verified. Do not store passwords, payment data, contracts, or highly confidential information in this app.
